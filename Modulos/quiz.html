MÓDULO 01

Fundamentos da Lógica Digital

Tudo começa com dois estados. Zero ou um. Falso ou verdadeiro.

O que é lógica digital?
Computadores processam informações usando apenas dois estados elétricos: LOW (0V) = 0 e HIGH (5V/3.3V) = 1. Toda operação lógica — desde somar dois números até rodar um jogo — é construída sobre combinações dessas portas simples.
0 1

Sistema Binário

Base-2: apenas dígitos 0 e 1 (bits). Um grupo de 8 bits = 1 byte. Toda informação digital é representada assim.


0 = FALSO = LOW
1 = VERDADEIRO = HIGH

Operadores Booleanos

Três operações básicas: AND (∧), OR (∨) e NOT (¬). Qualquer função lógica pode ser construída com elas.

Álgebra Booleana

As leis que governam a simplificação de expressões lógicas.

A Álgebra Booleana (George Boole, 1854) é um sistema matemático para trabalhar com variáveis que assumem apenas dois valores. É a base teórica de todos os circuitos digitais.

Circuitos Digitais

Combinando portas para criar funções complexas.

Circuitos Combinacionais — a saída depende apenas das entradas atuais.
Circuitos Sequenciais — a saída depende das entradas e do estado anterior (memória).

MEIO SOMADOR (Half Adder)

Soma 2 bits: Soma = A XOR B, Carry = A AND B

RESULTADO
0 + 0 = 0₂ (0)
SUM: 0  |  CARRY: 0

SOMADOR COMPLETO (Full Adder)

Soma 3 bits: A, B e Carry-In

RESULTADO
0+0+0 = 0₂ (0)
SUM: 0  |  COUT: 0

MULTIPLEXADOR 4:1 (MUX)

Seleciona 1 de 4 entradas com base nos bits seletores S1 e S0.
